================================================================================
                          HOW TO USE THIS GUIDE
================================================================================

OPTION 1: Open Locally (Recommended for Development)
-----------------------------------------------------
1. Navigate to the SystemDesign directory
2. Open the 'index.html' file in your web browser:
   - Double-click the index.html file, OR
   - Right-click and select "Open with" → Your preferred browser, OR
   - Drag and drop the file into your browser window

3. The guide will open in your browser with full functionality


OPTION 2: Using a Local Web Server (Recommended for Testing)
-------------------------------------------------------------
1. Open a terminal/command prompt
2. Navigate to the SystemDesign directory:
   cd /path/to/SystemDesign

3. Start a simple HTTP server:
   
   For Python 3:
   python3 -m http.server 8080
   
   For Python 2:
   python -m SimpleHTTPServer 8080
   
   For Node.js (if you have http-server installed):
   npx http-server -p 8080

4. Open your browser and go to:
   http://localhost:8080/index.html

5. Press Ctrl+C in the terminal to stop the server when done


OPTION 3: Deploy to GitHub Pages (For Sharing)
-----------------------------------------------
1. Push the files to your GitHub repository
2. Go to repository Settings → Pages
3. Select the branch containing these files
4. Your guide will be available at:
   https://yourusername.github.io/SystemDesign/

================================================================================
                          TROUBLESHOOTING
================================================================================

Issue: Styles not loading properly
Solution: Make sure all three files (index.html, styles.css, script.js) 
         are in the same directory

Issue: Navigation not working
Solution: Ensure JavaScript is enabled in your browser

Issue: Animations not playing
Solution: Try refreshing the page or using a different browser

Issue: Content appears broken
Solution: Make sure you're using a modern browser (see compatibility above)
